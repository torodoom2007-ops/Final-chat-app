# fackmy.IL — גרסת MVP משולבת Firebase

## מה כולל
- Firebase Authentication ו-Firestore עם הגדרות הפרויקט הקיימות.
- לייקים נשמרים במסמך נפרד לכל משתמש; המונה נקרא ממסמכי הלייקים כדי שלא לעדכן מסמך של משתמש אחר.
- משתמש רגיל: בדיקת צד-לקוח של עד 5 משתמשים חדשים ב-24 שעות ועד 150 הודעות ביום.
- Pro הדגמתי: כפתור מפעיל תצוגת Pro דרך קוד בלבד, ללא חיוב.
- כללי Firestore תואמים ל-MVP וכוללים הרשאות לצ'אטים, הודעות ולייקים.

## התקנה
1. שמור גיבוי של המאגר הקיים.
2. חלץ את ה-ZIP והעלה את קובצי האתר ותיקיית appimg לשורש המאגר GitHub.
3. ב-Firebase Console > Firestore Database > Rules, החלף את הכללים בתוכן `firestore.rules` ולחץ Publish.
4. ודא ש-Authentication מופעל עבור שיטות ההתחברות שהאתר משתמש בהן.
5. פרוס דרך GitHub Pages כרגיל ורענן את האתר עם ניקוי מטמון.

## אזהרות חשובות
- מגבלות 5/24 שעות ו-150 הודעות נאכפות כרגע בקוד הדפדפן ובשדות פרופיל. משתמש טכני יכול לשנות נתונים דרך הלקוח. אכיפה אמיתית מחייבת Cloud Functions/שרת אמין וטרנזקציות/מנגנון rate limit.
- Pro הוא מצב הדגמה הניתן להפעלה עצמית, ולא מנוי בתשלום. אין להשתמש בזה למנויים אמיתיים או להציגו כאילו בוצע חיוב.
- כל משתמש מחובר יכול לקרוא פרופילי users ונתוני likes לפי המבנה הנוכחי. לפני שימוש ציבורי אמיתי יש להפריד מידע פרטי כמו email למסמכים פרטיים ולבדוק פרטיות, גיל, דיווח וחסימה.
- כללי Firestore אינם מחליפים בדיקות בסביבת Firebase אמיתית. בדוק הרשמה, התחברות, לייק, פתיחת שיחה, שליחת הודעה, סטטוס seen, מחיקת חשבון ופרופיל.
